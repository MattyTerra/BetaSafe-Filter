BetaSafe-Filter is a project targeted at developing an open source image censorship software for nudes and lewds across the internet. It uses a fork of the NSFWSharp developed by ZygoteCode https://github.com/ZygoteCode/NsfwSharp as the base censor service and builds a GUI and improved functionality on top of it. 

This section of the project is for experiments related to either improving or experimenting with new methods of censorship.

Current ongoing experiemnts:
Making own internal model for censorship of nudes and lewds.
Using in plane rectangles within censorship.
Increasing the number of detection points. 
Realtime screen censorship.
